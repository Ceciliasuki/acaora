# UI references

PaperLab self-hosts Adobe's Source Serif 4 Regular under the SIL Open Font License 1.1. Source: [adobe-fonts/source-serif](https://github.com/adobe-fonts/source-serif), release branch, `WOFF2/OTF/SourceSerif4-Regular.otf.woff2`. The complete license and copyright notice ship in `public/fonts/source-serif/LICENSE.md`. The font is unmodified; no third-party font server is contacted while reading a paper.

The overview self-hosts a 7,448-byte Noto Serif SC Medium subset, generated by Google Fonts for the fixed display text `总览课程中心论文研究数据分析项目空间`. Source: [Google Fonts Noto Serif SC](https://fonts.google.com/specimen/Noto+Serif+SC), CSS API v2 (weight 500, text subset), retrieved 2026-10-15. Font bytes are served unchanged as `public/fonts/noto-serif-sc/Overview-Medium.ttf`; the SIL Open Font License 1.1 and copyright notice from [google/fonts](https://github.com/google/fonts/tree/main/ofl/notoserifsc) ship alongside it as `OFL.txt`. `Acaora Overview Serif` is the CSS family alias, confined to the overview display role; ordinary UI text retains the existing font stack. No third-party font server is contacted at runtime. If those fixed labels change, regenerate the subset or use a font covering the new text.

The button inset highlight in `app/white-theme.css` adapts the layered highlight approach from Magic UI's [Shimmer Button](https://github.com/magicuidesign/magicui/blob/main/apps/www/registry/magicui/shimmer-button.tsx). ACAORA uses a hover-triggered CSS sheen instead of the source's continuously rotating shimmer; no Magic UI runtime dependency is included.
