# 阅读工具界面复核

模式：full。范围：现有公共输入框/按钮/分段切换、PaperLab 标题与搜索、原 PDF 控件、引用与笔记汇总。Next.js 16.3.1 / React 19，沿用项目普通 CSS 和 CSS Modules。未重设计 Dashboard。

| 类别 | 实际检查 | 结果 |
| --- | --- | --- |
| Typography | 标题编辑、笔记原文换行、PDF 缩放数字、查看器按钮字体 | 原文允许换行，比例等宽数字，按钮继承页面字体 |
| Surfaces | 现有 tabs 圆角、输入焦点、PDF 弹窗、笔记汇总桌面截图与点击区 | 嵌套圆角对应内边距；手机 PDF、引用与汇总按钮至少 44px |
| Animations | CSS transition 指定属性、hover/focus/active 源码与实际焦点 | 使用可中断的 120–150ms 过渡；既有 reduced-motion 规则保留；10% 速度回放未验证 |
| Icons | 现有图标和新增控件 | 原图标保留；缩放使用可读符号与明确 aria-label；没有增加图标库 |
| Performance | PDF 懒加载、画布像素上限、指定 transition 属性 | PDF.js 按需加载；画布保留 1600 万像素上限；没有 transition: all 或长期 will-change |

| 严重度 | 位置 | 修改前 | 修改后 | 原因 |
| --- | --- | --- | --- | --- |
| MEDIUM | `app/globals.css` 标题/搜索输入 | 标题焦点仅下划线、搜索状态不一致 | 品牌色轮廓、弱背景及明确边界，沿用现有间距 | 便于识别当前编辑位置 |
| LOW | `app/globals.css` 现有 tabs | 嵌套圆角与层次缺少统一 | 外圆角 = 内圆角 + 4px；弱 hover、短过渡 | 提升状态清晰度，不增加导航层级 |
| LOW | `app/globals.css` 现有按钮 | 按压已有缩放但 transform 不在过渡中 | 120ms transform、弱 hover 轮廓 | 保持反馈克制且连贯 |
| LOW | `app/papers/original-pdf.module.css` | 原 PDF 按钮使用浏览器默认字体和固定焦点色 | 继承字体、品牌焦点及短反馈，比例等宽 | 与正文工具保持一致 |
| MEDIUM | `app/globals.css`、`app/focused-workspaces.module.css` 新引用/汇总 | 新入口在触屏上容易过密 | 触屏引用和汇总按钮至少 44px | 降低误触，保留桌面密度 |

| 位置 | 考虑过的方案 | 不采用原因 |
| --- | --- | --- |
| PaperLab 主导航 | 改成滑动胶囊 | 既有下划线样式已清楚，用户要求整体风格不变 |
| 搜索与按钮 | 霓虹、厚拟物、装饰徽标 | 会抢占阅读注意力并改变现有视觉语言 |
| UI 依赖 | 新增 Motion/Tailwind 组件框架 | 本次反馈可直接使用现有 CSS 表达 |

9 项 Windows 视觉基线在第一轮通过，未更新基线。实际查看本地生产构建的笔记折叠/汇总和桌面布局，检查原 PDF 实际画布截图；最终回归与正式站证据见[阅读工具发布记录](../releases/2026-10-05-reading-tools.md)。空状态、加载、键盘、移动布局另由现有回归覆盖。10% 动效回放和所有真实设备未验证。

结论：暂无剩余阻塞界面问题；短过渡的慢速回放未完成，不作为已验证项目。
