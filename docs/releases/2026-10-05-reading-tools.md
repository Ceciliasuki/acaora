# PaperLab 阅读工具与界面细节

2026-10-05（Asia/Shanghai）。本次按用户确认的优先项实施，与 PR #12 的[论文修复](2026-10-05-paper-fixes.md)一起发布。构建、合并和正式站的验证结果分别记录，合并前不把本地功能当作已上线。

## 本次范围

- 原 PDF 增加放大、缩小、适合宽度；按账号和论文在当前设备记住页码和缩放。点击 AI 原页引用时，指定页码优先于续读历史。
- AI 结果中的有效 `Pn` 可跳回当前论文的第 n 段；另提供对应原 PDF 页入口。超出当前段落范围的编号明确标为“无对应段落”。定位可用不表示模型引用的语义正确，仍需对照原文。
- 笔记与收藏按章节汇总，点击条目回到正文；Markdown 导出包含论文标题、文件名、P 编号、原页码、原文摘录和最新编辑内容。
- 新导入的普通双栏 PDF 优先按左栏、右栏顺序提取，兼顾轻微基线偏移、跨栏标题和数字表格的同行对应。新增七个解析单元用例与七个真实 PDF 格式的浏览器用例。
- 统一现有输入框焦点、分段控件层次和按钮反馈。沿用现有 CSS、品牌色、字体、阅读布局和下划线主导航，没有添加 UI 框架、服务或依赖。

已有论文不自动重新拆分，保留段落 ID、原文、笔记、收藏、译文和阅读状态。旧论文首次查看原 PDF 仍需在当前浏览器选择同一份文件。原文件不进入云同步，换设备或清理存储后需重新选择。

按用户取舍，本次不增加原页高亮/圈选批注、PDF 目录映射和手动章节编辑、文献属性/BibTeX 管理或复杂版面解析服务。双栏排序仍是启发式，不承诺任意表格、多栏、图注和扫描版均正确。
