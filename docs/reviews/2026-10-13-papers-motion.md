## 参考与判断

本轮用户确认“impact-cable”指 Impeccable。采用项目已有 Impeccable 的 `animate`、`delight`、`polish` 指南：这是需要频繁操作与长时间阅读的工具，动效负责状态反馈和空间连续性。主题是“展开页边，保留阅读现场”。没有将增加动画数量作为审美进步的证据。

- 若依官方前端仓库 [RuoYi-Vue3](https://github.com/yangzongzhuan/RuoYi-Vue3)。核查版本 `838965c5a18d2c61b73ec30c6e288057aaa08b63` 的 [AppMain.vue](https://github.com/yangzongzhuan/RuoYi-Vue3/blob/838965c5a18d2c61b73ec30c6e288057aaa08b63/src/layout/components/AppMain.vue) 和 [transition.scss](https://github.com/yangzongzhuan/RuoYi-Vue3/blob/838965c5a18d2c61b73ec30c6e288057aaa08b63/src/assets/styles/transition.scss)：用 `keep-alive` 保留页面状态、用内容过渡解释切换。Acaora 继续使用自己的 React/Next.js 架构和已挂载面板；借鉴状态连续性，没有迁移框架或复制 Vue 源码。若依的通用 `transition: all .5s` 没有照搬到频繁阅读操作。
- [Minimal Gallery 的 Bou 条目](https://minimal.gallery/bou/) 链向 [Bou 官网](https://wearebou.com/)。官网导航、留白和清晰文字层级经过浏览器观察；借鉴克制反馈，不使用它的全屏视频或素材。
- [Bou 的 Awwwards 记录](https://www.awwwards.com/sites/bou) 标注 **Honorable Mention，2026-09-11**。这是可核实的奖项记录，不是 Site of the Day。Minimal Gallery 本身是精选目录，入选不能自动等同于获奖。

这些参考只支持具体设计选择；不支持“本项目已经达到获奖水准”的结论。

## 已实现

1. 章节导航复用已有 `MotionNavigation`，2px 指示线在当前章节之间滑动，并提供鼠标与键盘聚焦反馈。原有章节跳转和段落定位保留。
2. 论文库与笔记打开时采用小幅横向进入；正文通过水平位置衔接说明页边空间变化。进入 260ms，布局衔接 220ms，章节指示 280ms；无等待、分段入场、正文缩放或纵向位移。
3. 阅读、AI 分析、检索和手机标签切换立即提交状态，面板维持挂载，查询与草稿继续保留。重复切换从当前视觉位置接续，旧动画取消，不排队播放。
4. 运行中开启系统减弱动效会取消移动，当前选中项、可见面板和文字反馈保留。断点变化与卸载清理动画。内容默认可见，不依赖入场动画才能显示。
5. 最终视觉复核发现论文库行仍使用横向 flex，新增文件名挤占标题列，使名称呈单字竖排。将该行在 `/papers` 范围内改为标题/删除操作两列，文件名单独占下一行；与动效共同保证展开后内容可读。

仅使用已有组件、CSS 与原生 Web Animations API，没有增加依赖。没有修改共享导航实现、总览、认证、同步协议或存储结构。
