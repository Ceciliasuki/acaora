# DataLab 界面整理 · 2026-10-21

本轮按用户“按照之前优化 UI 的步骤和参考网站以及标准”的要求，对 `/data` 做局部界面优化。沿用浅色学术工作台、系统中文字体、产品蓝和既有组件；未改统计引擎、存储协议或账号边界，未部署生产。

## 依据与流程

先审查当前源码、上一轮生产构建截图、`DESIGN.md`、`PRODUCT.md` 和历史参考记录，再确定局部方案并实现；执行功能测试、桌面／中间宽度／手机视觉及无障碍检查，集中修正一次后确认收尾。用户此次直接要求优化，实施范围沿用既有视觉体系。

使用 Impeccable 的 layout／polish 与 craft-floor 指南。`DESIGN.md` 禁止执行下载的 Impeccable 二进制，因而本轮未运行 launcher、hook 或原生 detector；人工检查未被描述成检测器报告。本轮没有运行独立双评审者或奖项评审。

参考沿用已在项目内核查并留档的材料，未声称本轮重新浏览或验证网站：

- [若依与 Bou 的参考记录](2026-10-13-papers-motion.md)：状态连续性、明确的导航和克制反馈。
- [Developments、Siena、Exat、Rijksmuseum 的参考记录](2026-10-15-overview-taste.md)：单一主层级、稳定入口、依靠文字和留白组织内容。实际查看了已归档的 Developments 参考截图；没有搬用展示字体、暗色主题、素材或大媒体构图。
- [Awwwards／Webby／FWA 标准记录](2026-10-14-papers-industry-audit.md)：分别借鉴视觉与可用性平衡、内容与导航及功能完整性、创意与交互的质量要求，不编造 FWA 权重，不声称达到奖项等级。

## 本轮变化

- 顶部由完整上传卡片与大型概况面板改为紧凑的数据条，保留实际文件名、样本量、变量数、缺失数、处理步数和示例标记。可直接打开系统文件选择器；原拖放入口与格式说明按需展开，导入状态与错误仍直接可见。
- 处理工作台与变量检查默认收起。原生 disclosure 支持键盘，折叠不卸载组件、不清除草稿或正在进行的 Worker。分区导航可自动展开对应区域；历史增加独立导航入口。
- 数据处理在宽屏上按“操作设置／步骤记录”并排。处理方案及文件导出收进命名明确的原生 disclosure，保留全部操作。
- 多元回归、进阶方法在 1180px 以上按“左侧设置／右侧结果”并排；窄屏转为上下排列。未运行时结果区给出实际下一步说明，不显示虚构图表。原错误、取消、检查、旧结果和参数修改提示继续可见。
- 基础方法的固定、复制、快照及复现工具移到可见结果之后；分析历史放在结果之后，仍可从分区导航直达。
- 内容组织以连续白色工作面、标题和细线为主，减少独立卡片与阴影。使用既有 `--border-control`、`--text-2` 和蓝色焦点；数字采用 tabular figures，表格与科学图形保留局部滚动和实际导出尺寸。
- 保留既有主导航、背景开关、认证、当前来源及数据失效合同。没有更换全站主题、引入 UI 库或增加装饰动画；仅为 disclosure 箭头保留 180ms 状态反馈，尊重 reduced motion。

实现入口：`app/data/data-studio.module.css`、`page.tsx`、`data-workbench.tsx`、`multiple-regression-panel.tsx`、`advanced-panel.tsx`、`multiple-regression.module.css`。

## 验证与证据

生产构建和内置 TypeScript、相关源码 ESLint 通过。21 个相关生产 E2E 通过，覆盖既有 OLS／进阶流程和工作台、快照／账号隔离、导出，以及新增界面行为。首次视觉检查发现手机统计标签过窄、导航仍被旧样式渲染为浮起卡片，已集中修正；只重新执行 4 个相关 UI 用例，全部通过。

新增 UI 用例覆盖 1440／1024／375px：实际文件选择器、默认折叠、导航展开、键盘 Enter、草稿保留、真实拟合结果的左右／上下布局、旧结果提示、reduced motion、页面无横向溢出。Axe 的 serious／critical 筛查通过；该筛查不代表完整 WCAG 认证。新数据条的控件边界与正文色对比在真实计算样式上分别通过 ≥3:1 与 ≥4.5:1 门槛。

证据：`outputs/data-studio-ui-2026-10-21/`，包括三个宽度的 `entry-*`、`processing-*`、`model-*`、`page-*`，以及 `classification-1440.png`。截图中的 `study.csv` 是可复算测试数据，不是用户的研究结果。上一轮数值复算证据因统计引擎未变而复用，未重复运行 31 组 Python／R 复算。

保留现有科学图形的最小预览宽度，窄结果区可横向滚动；导出仍按用户所选尺寸。当前为本地界面实现与受控浏览器验证，没有真实生产账号验收或真实用户性能测量，不宣称性能提升或全站获奖水准。
