# 论文阅览室 · 重构与自检

## 方向与范围

用户于 2026-10-14 明确允许大范围重构、替换现有界面。本轮替换 `/papers` 的空间结构和视觉表达：以论文自身为中心，采用平整白色阅读空间、大幅衬线标题、连续书页、吸顶工具带、临时论文库抽屉和当前段落的笔记页边。

旧界面的约束是两层工具栏、固定在正文外的标题、长期占据宽度的资料区，以及多个样式文件共同支配布局。新的路由样式独立于 `focused-workspaces.module.css`，相关决策已写入 DESIGN.md 的 Reading Room 小节。已有品牌钴蓝、浅色模式和 AI 来源区分仍保留；总览与其他页面的视觉没有重画。

参考延续上一轮已核查的若依状态保留思路、Minimal Gallery 收录的 Bou 与其 Awwwards Honorable Mention 记录，来源详见 [动效参考记录](2026-10-13-papers-motion.md)。借鉴的是有用的连续性、清晰导航和文字层级，不复制页面或素材。框架继续使用现有 React/Next.js，没有迁移若依。

本轮使用 Impeccable 的 new-work、craft-floor、animate 和 polish 指南。DESIGN.md 禁止运行下载的 Impeccable 二进制，因此没有执行 concept-seed、原生检测器或正式双评审者 critique 流程；方向由授权范围内的设计判断形成，验证依靠渲染与回归。没有将这些替代检查描述成插件检测器报告。

## 实际改变

- **论文成为主要对象。** 桌面标题 44px、手机 32px，使用已有自托管 Source Serif；完整标题仍可编辑。文件名、段落数、章节数来自实际记录。正文桌面 20px、手机 18px，桌面最大 72ch。
- **连续阅读。** 标题和来源信息与正文共用一个滚动区域；阅读深入后标题自然离开视口。章节、原 PDF 与译文开关组成吸顶工具带，正文定位计算同时考虑它的高度，手机还考虑顶部面板标签。
- **资料按需出现。** 论文库为临时抽屉，打开时不压缩正文。选择当前或其他论文会返回阅读界面；支持 Escape 收起并恢复焦点。旧的“长期展开论文库”偏好不再导致启动遮挡，原偏好数据格式保留，没有迁移论文数据。
- **笔记有明确上下文。** 当前段落编辑区先出现，笔记汇总和划线批注随后。桌面笔记与原文并排；较窄桌面采用更紧凑的两行工具带；手机使用独立工作面板。
- **动效保持可中断。** 延续 220–280ms 的页边展开、工作模式与章节指示反馈，正文不缩放或纵向入场。动态减弱动效、快速切换、草稿与查询保留均有专项检查。
- **背景真正停止工作。** 论文页不显示背景画布及其开关。共享画布通过可见性观察停止隐藏绘制，返回其他工作区恢复原动效开关状态；没有强行修改用户偏好。

原 PDF 字节、段落 ID、批注、翻译、笔记、书签、进度、账户边界、离线队列和异步来源归属的实现合同保留。没有正式站部署、付费 AI 调用或真实账户写入。

## 八项自检与优化方案

| 维度 | 本轮自检及处理 | 后续最有价值的优化 |
| --- | --- | --- |
| 排版 | 标题、章节、正文与页边形成明确尺度；修正大字体输入框行高和旧的图标按钮宽度；去掉残留正文内框。 | 用真实中文论文和中英混排检查字体回退、公式与参考文献的阅读效果。 |
| 留白 | 以单一书页和有限正文行长组织空间；滚动条两侧对称占位，正文居中；论文库不挤压正文。 | 让学生进行长时间阅读，决定标题与正文之间的最佳密度。 |
| 视觉层级 | 论文标题是视觉中心；工具带保持可用，笔记先服务当前段落；背景退场。 | 对超过十个章节的文献验证索引滚动与当前位置的可发现性。 |
| 色彩 | 白色、项目正文色与钴蓝承载普通操作；没有新增渐变或第二套品牌色，AI 来源语义保留。 | 真实显示器、低视力和不同亮度环境下的对比度复核。 |
| 动效 | 快速切换可以取消旧动画；支持运行中开启减弱动效；隐藏背景停止绘制并可恢复。 | 在实际低功耗设备测量掉帧、输入延迟与耗电，当前没有真机帧率结论。 |
| 微交互 | 原 PDF、译文和章节在长阅读中保持可操作；抽屉 Escape、手机方向键标签导航、关闭后焦点恢复和标题输入法行为保留。 | 实机长按选字、软键盘弹出与跨段批注联动。 |
| 响应式 | 长标题覆盖 1440、1024、768、375px；阅览室专项检查桌面、平板和手机；窄屏笔记不再盖住原文。 | Safari、iOS/Android、200% 浏览器缩放与完整屏幕阅读器测试。 |
| 原创性 | 以实际论文、来源记录和页边工作形成统一构图，版式与动效由阅读机制推导；没有装饰性数字、假作者或营销素材。 | 独立设计评审与实际学生使用反馈，验证它是否具有奖项竞争力。 |

自检能证明处理了具体缺陷，不能替代奖项评审，也不提供虚构的审美分数。
