实施从 2026-10-24 延续到 2026-10-25，分支 `codex/research-continuity-2026-10-24`。保持已有研究设计、分析登记和证据关联，课程仍相对独立，未改 Dashboard 或阅读器的主体排版。

## 可使用的能力

| 项目 | 入口与实际行为 |
| --- | --- |
| 方案版本 | 项目 → 研究记录与交付 → 方案版本。冻结服务器已保存的设计，记录阶段与理由、逐字段比较、原子恢复并追加修订版本；已有分析不能再标为首次分析前计划。 |
| 项目备份与恢复 | 导出项目主体与所有研究事件，校验内容哈希、版本连续性和项目归属；先预览，再明确创建新项目。相同恢复操作幂等，保留原项目，已删除副本不因重试复活。 |
| 复现核验 | 新快照包含完整精度基线；DataLab 从原表重放处理步骤与模型，再比较引擎、配置、原表/处理表指纹及数值容差。支持导入新 Python/R 输出，保留环境版本。旧快照无基线时不判通过。 |
| 数据来源与谱系 | DataLab 捕获当前原表、处理表 SHA-256、行列数与实际步骤；项目补充机构、网址、许可、观察单位和样本范围；追加版本须满足父指纹约束。 |
| 文献证据矩阵 | 从项目原文摘录建立证据行，保存研究问题、样本、设计、发现、局限、筛选决定与排除理由；矩阵可比较并返回原文。书目元数据需研究者核对，未确认项目不进入参考文献。 |
| 模型与稳健性矩阵 | 从当前 DataLab 模型及处理步骤登记规格，关联方案；最多 12 项串行执行，全部成功、失败和取消均留档。待上传结果本机保存，重试只登记，不重跑。项目可比较最多六项运行的所有返回指标。 |
| Word / LaTeX 交付 | 下载真正的可编辑 DOCX，或含 main.tex、references.bib、PNG 图件的 ZIP。包含研究设计、分析设置/表格、证据原文、结论、谱系、规格、核验和审阅记录；匹配本机完整快照后才加入图表，缺失快照明确标注。文件 SHA-256 与实际来源版本登记到项目。 |
| 审阅与修订清单 | 问题分类、严重程度、负责人、来源关联、解决状态和处理依据；解决/不采纳须填理由，未解决阻断项不能归档，并要求明确以工作稿导出。每次保存保留旧版本。 |

## 数据与发布边界

- 云端记录研究元数据、配置、摘录和汇总结果；不新增原 PDF 或数据行上传。本机快照需另行 JSON 备份；项目备份不包含本机完整快照和原始文件。
- 工作台记录不等同于第三方预注册、同行审查、因果识别通过或研究结果得到验证。外部结果文件由研究者提供；脚本核验实际处理表和设置，原表身份是清单声明。
- 外部完整指标映射覆盖描述统计、相关回归和 OLS。其他方法可在浏览器重跑，但不会把外部部分指标视为完整复现通过。
- 记录按所有者 RLS 隔离，只追加历史。显式删除整个项目仍级联删除其研究事件；重要项目应提前备份。
- 单项目 2,000 事件、约 8 MiB 负载预算；备份限制 20 MiB。Word/LaTeX 文件有体积与图件上限，超限报错，不静默截断交付。
- 新增迁移 `20261024144054_research_workbench_records.sql` 已通过 PGlite 隔离验证，并应用到已核实项目 `pxbcigfzcsfkttzmiork`。新增两表、所有者策略与受限 RPC；旧 JSON、论文、课程记录不迁移。公开函数均为 invoker；私有原子恢复函数为限定 search_path 的 definer，仅创建当前所有者的新项目。
- 新版前端仍在本地，未提交、未发布。回退前端可继续使用旧项目 JSON；保留新增表，不做删除性收缩。
