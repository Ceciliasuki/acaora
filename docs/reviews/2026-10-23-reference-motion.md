# 参考网站动效借鉴实施 · 2026-10-23

本轮落实六项建议，不部署：

1. 首页原文、关键句和笔记示例可分步查看、播放、停止和重播。内容始终可读，工作台入口保持可用。
2. 首页导航、模块箭头和帮助链接统一短反馈，键盘聚焦有对应提示。
3. 章节/段落跳转后短暂强调原文；新批注的原文高亮和笔记按相同批注 ID 同时提示，编辑器出现时也有提示。没有改动正文、保存协议或阅读锚点算法。
4. 首页介绍、工作区与文件说明各自只进入一次；默认内容可见，离开页面或开启减弱动效取消运行。
5. 课程大纲、数据分析提供默认收起的三步说明。说明选择不会写入学习进度或改变数据与分析设置；既有真实图表动画保持使用。
6. 沿用现有导航、面板和低频背景体系，背景保持默认静止、显式开启；未加持续漂浮或全局滚轮接管。

## 最终交互触发修正：悬停与复原

用户澄清需要鼠标移入元素产生动效、移开恢复。首页现增加标题行的轻微位移/倾斜、原文和笔记纸页的抬起/转动/轻微放大，以及工作区入口的错层移动与细线展开。纸页通过独立 translate/rotate/scale 属性叠加在当前演示姿态上，不覆盖演示 transform；移开回到当时的原姿态。正文保留选字能力。

取消了首页示例自动播放，保留主动播放和重播。空间悬停只在 fine pointer、hover 可用且非 reduced-motion 下生效。

本轮仅执行受影响的三个场景：桌面移入及移开精确复原（含减弱动效静止）、375px 手动示例、实时减弱动效，3/3 通过。未重复论文、课程和数据场景，未部署。

## 全站悬停反馈

用户将范围从首页扩大至所有界面。本轮通过根布局加载共享 CSS，覆盖总览、课程列表、课程阅读、论文库、论文阅读、数据分析、项目、设置、帮助、登录/注册和密码返回页面；各页无需重复绑定鼠标监听。

普通启用按钮轻微抬起，列表只移动标题或图标，选项卡/导航目标保持几何稳定并使用内侧底线。正文与编辑内容不移动；输入区只改变边框颜色，原有焦点描边保留。触屏与减弱动效模式不启用空间悬停。没有改动数据操作。
