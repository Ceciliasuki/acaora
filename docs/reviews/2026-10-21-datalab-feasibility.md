# DataLab：进阶方法的可用性与复现

2026-10-21，本地实现；未部署到 acaora.cn。承接 `2026-10-21-advanced-methods.md` 的十种方法，本轮新增 Welch ANOVA，合计十一种。

## 本轮交付

### 运行前的数据与设定检查

新增显式“检查数据与设定”，在 Worker 中计算完整样本数、排除行数、每个所需字段的缺失/非法数值数量、有效组数与每组样本范围；按方法补充 0/1 编码、零配对差、主体内不变变量、基本参数范围、残差自由度和可用分折规模等检查。

同一行可有多种排除原因，因此字段计数不能直接相加为排除行数。只检查所需字段；无关列缺失不影响当前模型。设置变化后检查结果明确标旧，不自动修改原始数据、删除变量或重编码类别。超过 20% 排除、较少聚类或疑似唯一标识变量只给出具体提示，不把阈值当统计保证。

界面按当前方法说明自动检查的范围与人工判断的条件，独立性、正态性、同方差、因果设计和预测时变量可用性不会被样本计数“认证”。只有实际数据问题进入结果提示，不在 PCA/K-means 结果中附上回归分离或同方差的泛化警告。共线性、Logistic 分离边界和收敛仍由实际模型计算进一步检查。

### 可重新载入的进阶方案

新增“保存与载入进阶方案”，区别于已有只读分析记录。方案包含完整配置、引擎版本、缺失规则、SHA-256 数据指纹、表头/行数和时间，不含原始数据行。

- 严格 `acaora-advanced-recipe` v1，当前引擎 `acaora-advanced-v2`；256 KB 上限，拒绝未知字段、重复变量、无效参数、错误数据标识、记录文件和旧引擎文件。不执行导入内容。
- 逐个映射当前方法的必需变量，检查字段存在、所需数值类型和角色冲突。主体字段允许文本或数值。
- 指纹不同必须明确勾选“我已核对映射，使用当前数据”；映射再次改变会撤销确认。
- 可跨方法载入；应用会切换方法并清除旧面板状态，只填入设置，不自动计算。用户仍需手动检查和运行。
- 原有基础分析与 OLS 方案格式保持原合同；原 v1 进阶“分析记录”不会被伪装成可运行方案。

### 更贴合数据结构的交叉验证

原有随机模式保留，名称改为“线性回归交叉验证”，增加“验证划分”下拉框：

| 模式 | 划分规则 | 输出与边界 |
|---|---|---|
| 随机 K 折 | 原有 LCG + Fisher–Yates、按行随机分折 | 适合独立样本；同一主体记录或未来信息不能依靠随机分折解决 |
| 主体分组 K 折 | 排序后的唯一主体按相同种子分折；某主体的全部记录只在一折验证 | 每折训练/验证主体完全隔离，附主体数量和零交叉检查。按主体数近似均分，观测数可能不均衡；评估新主体泛化，不同时保证时间顺序 |
| 时间前向 | 数值时间值排序后按不同时间点分为 K+1 块；同一时间点不跨块，每折仅训练于更早块 | 最早块只用于初始训练；预测、残差和验证折保持空值，不计入折外指标。附逐折时间范围。支持数值年份/时间戳，未自动解析文本日期，未提供 gap/purge/滚动固定窗口 |

各折仅使用训练样本拟合缩放和含截距 OLS；验证集保留原值。时间字段与模型变量分别设置，当前要求字段角色不重复；训练集必须大于参数数且设计矩阵可识别。预测指标基于有折外预测的观测计算，另报告评估 N 与初始训练 N，不把缺少预测填成 0。

没有增加嵌套调参、自动选变量或最终全样本模型；主体与时间同时约束、重叠标签窗口、复杂金融预测仍需专门设计。

### Welch 单因素方差分析

新增允许各组方差及样本量不等的 Welch ANOVA，输出 Welch F、分子自由度、Welch–Satterthwaite 分母自由度、p 和各组摘要。要求 2–100 个有效独立组、每组至少两个观测且各组方差正且有限。仍需考虑组内分布与独立性，不自动宣称某两组有差异，也不鼓励在两种 ANOVA 间按 p 选结果。未增加事后多重比较。

## 后续建议及成本

| 优先级 | 建议 | 价值与需要先解决的条件 |
|---|---|---|
| 高 | 明确编码的分类解释变量、参考组和交互项 | 直接解决真实数据回归入口。需要保存水平/参考组、固定训练集编码并正确处理验证集新类别；不能只临时把文字变数字 |
| 高 | 事后比较与多重检验校正 | 衔接多组分析。先确定比较族和比较问题，可从成对 Welch + Holm 开始；不批量挑显著结果 |
| 高 | 可编辑的论文图表导出 | 从系数区间图、PCA 碎石图与验证误差图开始；保留数据源、N、单位、方法和导出精度，支持 SVG/PNG 与图下注释 |
| 中 | 可追踪的数据变换步骤 | 筛选、缺失处理、对数/标准化和哑变量须记录顺序、参数、原列与派生列，能撤销；避免默默修改源文件或导致验证泄漏 |
| 中 | K-means 稳定性与 K 比较 | 多种子对比、组规模与稳定性先于“最佳 K”按钮；轮廓分数需计算预算，不能无上限做全对距离 |
| 后续专题 | 双向固定效应、DID/事件研究、IV 与 Bootstrap | 应单独设计时间/主体键、识别假设、标准误、前趋势/工具强度或重抽样单位；不适合仅作为一个新菜单拼入 |

本轮只实现前述四项可交付改进，以上后续建议尚未实施。
