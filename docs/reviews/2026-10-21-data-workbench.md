## 功能口径与边界

- **数据处理**：文本／数值条件筛选、单列缺失删除、常量／均值／中位数填补、精确文本重编码、新列对数／平方／Z 标准化／四则运算。保留导入原表；每步从原表顺序重算，可撤销最后一步或恢复原表。记录前后 N、变化记录、拟合参数、无效输出和原表行号映射。处理方案可导入导出；来源指纹变化必须确认后应用，并重新估计处理参数。最多 50 步、100,000 行；无效数值派生留空，不覆盖原列。
- **变量字典**：显示名、角色、单位、统计口径、来源、引用／DOI／链接、期间；支持严格 JSON 导入导出。说明由用户维护，不代表系统已核验来源真实性，也不自动改变数据类型。
- **面板体检**：主体与数值时间键、缺失／非法键、重复键及对应行号、共同期间平衡、按预期间隔识别相邻缺口、主体内变量是否变化。输出逐主体与重复键 CSV；不自动删除或补齐。改变数据或设置会标记旧报告；单列变动检查的样本可能与模型完整样本不同。
- **命名快照**：保存实际分析配置、摘要、汇总结果表、默认图形、数据指纹、处理记录和变量说明；不保存原始数据行或逐行预测表。支持重命名、删除、导出 JSON、查看和双版本摘要对照。登录用户按服务器确认的用户 ID 存储于本浏览器 localStorage；访客仅当前标签页 sessionStorage，身份变化清除访客记录。每次写入前重新确认身份；失败不覆盖旧存储。最多 20 个、单个 2 MB、合计 4 MB。无云同步，也不自动重算历史；编辑后的图表标题与图注需另行导出图文件。
- **复现包**：ZIP 包含 `analysis.py`、`analysis.R`、实际 `manifest.json`、Python 固定依赖和运行说明；Python 3.12+，R 4.4+ 另需 jsonlite／digest。默认不附带数据，用户明确勾选后才加入所有当前处理表行；也可单独导出 `analysis-data.json`。两种脚本对该文件的精确字节做 SHA-256 校验，再重算分析并输出结果／依赖版本。脚本重算处理表上的分析，不自动重放原始 CSV／Excel 处理链。数据 JSON 必须保持原字节，连额外换行也会导致校验失败。
- **分类预测验证**：Logistic 随机 K 折、主体分组、时间前向验证；各训练折单独拟合类别编码和模型，汇总折外概率。输出 ROC-AUC、AP、Brier、截断概率对数损失、预先指定阈值下混淆矩阵及 precision／recall／specificity／F1，等宽 10 箱校准描述及完整 ROC／PR 曲线。AP 按召回增量加权，不是 PR 梯形面积；空校准箱不画点。训练折少类、分离、未知类别或秩亏会停止而不跳折；随机验证未做类别分层。最多 10,000 完整观测，2–10 折；时间首块仅训练，无时间隔离间隔或清除重叠标签窗口。未提供这些评估指标的区间，也不以本验证标签自动调阈值。
- **Bootstrap**：均值、配对均值差、两组均值差、Pearson 相关；独立行或完整主体有放回抽样，固定 LCG 种子。独立行的两组均值差在组内抽样，主体抽样保留主体全部完整观测；原估计仍按行加权。100–2,000 次，最多 20,000 完整观测；预计处理预算 2,000 万行，主体不平衡的实际预算 2,500 万行。报告原估计、重抽样 SE、type-7 百分位 95% 区间、有效／失败次数及每次抽样结果；有效次数不足 95% 拒绝区间。没有 BCa、Bootstrap p 值或时间区块抽样。

全样本拟合的均值／中位数填补、标准化及相关派生列被追踪；如果所需预测字段或样本选择受其影响，交叉验证与分类验证会阻止运行，提示撤销。该保护较保守，不能替代研究者对预测变量可用时间、调参和独立测试集的设计。

进阶方案引擎为 `acaora-advanced-v4`，兼容合法旧 v3／v2 方案；新方法不能伪装成旧引擎方案。基础分析、OLS 和既有十二种进阶方法保持原入口。
