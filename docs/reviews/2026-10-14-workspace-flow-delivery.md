# 桌面工作流第二轮优化 · 2026-10-14

继续推进已批准的桌面 UI 优化，围绕真实长任务的操作效率与结果核对。复用现有统计计算、账户 API、按钮、导航动效和浏览器剪贴板，没有新增依赖、数据模型、部署或真实账户操作。

## 本轮交付

| 场景 | 新交互及边界 |
|---|---|
| 项目较多 | 按项目名称或目标查找；无匹配时提供查看全部。项目列表支持上下键、Home、End 自动切换；输入仍按原项目保留。列表在桌面有独立滚动上限。 |
| 任务较多 | 全部／待办／已完成筛选及实际数量。筛选按当前项目保存于页面会话；任务标记仍走原有成功确认流程。某行从筛选中消失后，焦点回到可用任务或筛选入口，用户主动移开焦点时不抢回。任务列表独立滚动，减少长列表挤压笔记。 |
| 连续选择变量 | 固定一份真实结果，保持指标值，继续选择当前变量或方法。对照默认折叠，可随时替换或取消；两栏明确方法和变量。没有相同指标或当前分析无有效结果时显示破折号及说明，不伪造零值或差异推断。 |
| 记录分析结果 | 复制当前结果，包含文件名、示例标记、方法、变量／检验条件和页面数值精度。只有剪贴板成功后显示已复制；权限失败提供可选中的文本供手动复制。副本不含原始数据行。 |
| 数据更换 | 原文件成功重新读取或恢复示例时清除旧固定结果及复制反馈。同名文件也触发清除。对照只属于当前页面会话，不存入账户，不作为正式研究结果导出。 |

## 设计判断

保留浅色工作台、品牌蓝和既有排版。新增界面从属于当前任务：查找留在项目目录内，状态筛选留在任务清单内，对照按需展开。沿用现有指示线与减少运动规则；没有添加游标装饰、背景特效或新动画运行时。总览构图与手机视觉对齐范围维持此前约定。
