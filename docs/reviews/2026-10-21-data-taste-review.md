## 设计判断与边界

设计判断：供长期使用的论文数据工作台，真实图表与分析结果应成为主画面，来源、方法、记录围绕它展开。

使用本地 `design-taste-frontend` 的 redesign-preserve 模式。DESIGN_VARIANCE 6 / MOTION_INTENSITY 2 / VISUAL_DENSITY 6。依据当前 `DESIGN.md` 保留 Segoe UI / 中文系统无衬线、品牌蓝 `#305fce`、12px 文字下限、已有 Lucide 图标与减少动态效果支持。

该 skill 的第 13 节明确排除 dense product UI / data tables。因此本次采用其构图、排版、容器克制、设计审计与 pre-flight 方法；不将营销首屏、大图、滚动叙事、组件库安装、暗色模式或“每区不同布局”的规定强套到统计工作台。下文是设计判断，不是外部奖项评分，也不声称完成了用户审美验收。

## 对上一版的 taste 评审

1. **构图缺少主角**：导入、处理、检查、探索先后占据横向条带，图表在多次扫描之后才出现。删除卡片并未自动形成好构图。
2. **视觉权重平均**：多个同级标题、边线与折叠行连续出现；用户难以区分核心工作和附属工具。
3. **工具先于内容**：五个方法平铺在横向页头，缺少稳定的工作区关系；功能数量增长后更像设置集合。
4. **数字与图表缺少尺度角色**：关键统计数、图表标题和辅助说明没有足够差距，信息可读但缺乏视线顺序。
5. **手机端只有堆叠**：隐藏分区导航虽然减少一行，却降低了处理、历史等较远区域的可达性。

## 本次修改

- 先展示数据来源，再展示完整分析画布；处理、检查、探索、历史和处理表继续保留原有 ID，可从分区导航直达。只改变页面内容摆放，不改变路由和全站导航。
- 桌面分析画布采用 164px 方法目录与主结果区域；方法状态用品牌蓝与短选中标记表达。1180px 及以下改为横向方法条，手机使用局部横向滚动，避免五个方法占据多行。
- 图表为最大主体，统计摘要为次级的浅灰区域。保留真实频数、变量与摘要，不放假图、假指标或宣传性插画。
- 来源区使用文件名、行列数与真实缺失数，导入按钮保持突出；“恢复示例数据”移至来源区，减少手机页头高度。
- 对字段表、摘要和结果使用对齐的数字；图表标题 24px、主要摘要数 40px、辅助字 12–14px，沿用当前字体，不增加外部字体或请求。
- 竖向方法目录提供上下键、Home/End；较窄布局继续使用左右键，`aria-orientation` 跟随断点。共享 MotionNavigation 仅新增可选语义属性，既有调用保持原行为。
- 调整柱体可用高度，给频数标签固定留出 22px，避免最高柱受 flex 收缩而失真。没有改动统计计算；检查的是实际柱高与频数的比例。
- 保留处理草稿、文件锁、Worker 生命周期、数据切换键、旧结果失效与鉴权清理等已有契约。

### Pre-flight 适用项

- 已声明设计判断、模式、三个 dial 与现有品牌系统。
- 同一浅色主题与蓝色动作语义；沿用项目 6 / 8 / 12px 控件、区域和主画布圆角角色。
- 按钮标签不被拆成两行，输入边界、正文对比与焦点可辨；不新增悬停才可发现的核心操作。
- 方法选择只做已有短状态反馈，减少动态效果仍可操作；无新动画依赖。
- 断点明确；宽表在有名称的局部区域内滚动，页面不横向溢出。
- 原有空、加载、错误、无效结果状态保留。表中缺省值的“—”是研究数据语义，保留以维持现有输出契约。
- Hero、照片、logo 墙、营销 CTA、引言、双主题等检查不适用于本工作台，记为 N/A，不伪称全项通过。
