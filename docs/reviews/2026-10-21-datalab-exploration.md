# DataLab：数据诊断、分组探索与统计可靠性

日期：2026-10-21。本地实现，未部署。延续[前一批分析方案复用](./2026-10-21-research-workflows-implementation.md)，本轮先补通用研究基础，而非把文件格式支持数量当作分析能力。

## 本轮新增

入口：`/data`，变量检查之后的“数据诊断与探索”。按需展开后计算，不默认展开矩阵。

| 功能 | 行为与计算口径 |
| --- | --- |
| 质量诊断 | 每列显示缺失、非数值、有效数值 N、不同原始值、常量/全缺失；查找变量；整行完全重复按多余行计数，不自动删除 |
| 分组汇总 | 按一个变量分组或不分组；显示有效 N、缺失、非数值、均值、样本标准差、最小/最大值及 Q1/中位数/Q3；分组缺失未入组的行单独报告 |
| 频数分布 | 任意一列的值与频数、有效百分比；百分比分母排除缺失；按频数降序 |
| Pearson 相关矩阵 | 选择 2–12 列；每对使用完整有效观测，分别显示 r 和 N；常量或不足 3 对显示不可计算；点击有效非对角项打开已有散点图/回归 |
| 表格导出 | UTF-8 CSV，保留计算精度；相关矩阵导出变量对、r、N；转义引号和可能被表格软件当作公式的文本，不导出逐行原始数据 |

页面表格最多显示前 50 行；导出包括当前筛选/选择的全部汇总结果。分组超过 200 个不同值时明确拒绝，未静默丢组。不同原始值保留文本差异；没有自动去重、填补、缩尾或删异常值。

## 修正的统计问题

复现：常量 X/Y 或两组均为常量时，原计算产生 `NaN` 统计量；`studentTPValue` 对所有非有限 t 直接返回 0，页面随后可能把无效检验解释成显著。

- 无效 t/自由度返回不可计算，不能变为显著性证据。有效自由度下无限 t 的数学极限仍为 p=0。
- 少于 3 对观测、常量 X/Y 的相关回归不可计算；Welch 标准误为零或非有限时不可计算。
- 无有效样本的描述统计、单个观测的样本标准差不再伪装成 0。
- CSV、Excel/文本矩阵、统计软件文件统一消除重复列名，处理自动生成后缀碰撞，避免后续按列名分析时取到第一列。
- 直方图改用迭代求边界，避免大数组作为函数参数展开的数量限制。此项不代表全套分析已通过大数据性能验收。

新的方案继续使用 version 1 文档结构，统计引擎标记改为 `acaora-stats-v2`。旧 `acaora-stats-v1` 方案可读取，但必须明确确认后用新版重算；不无提示宣称旧结果完全复现。

## 还未加入的能力与建议顺序

当前仍是浏览器端研究探索工具。矩阵只显示线性关联，不做因果或多重显著性筛选；分组描述不等于组间差异检验。现有自动数值识别使用 80% 阈值，尚不能手动声明测量尺度；数值编码可能仍应作为类别对待。

下一阶段建议优先：多元 OLS → 常规/HC3 标准误与系数置信区间 → 残差、共线性和影响点诊断 → 多模型比较与可复现导出。应使用成熟数值实现并与可信参考结果核对；不要直接用矩阵求逆拼出一个没有病态/共线性处理的回归器。

再根据实际数据决定是否加入配对/非参数检验、Logistic、面板固定效应或数据清洗。原始数据留在浏览器的合同应继续保留；大文件的 worker/绘图策略需要独立性能验证，不由 20 MB 文件上限推断可用观测数。
