# 奖项标准审视：修改清单与自检

2026-10-15。审视对象为正式站 `https://acaora.cn`（线上实测）与当前主分支代码（静态审计）。本文只做诊断与方案，不改动代码。

**证据标注约定**

- `[实测]` 来自本次在正式站上的真实测量（计算样式、截图、DOM）
- `[代码]` 来自对当前主分支 CSS/TS 的静态审计（含 file:line）
- `[推断]` 由上述两者推导，未直接测量
- 凡未实测的审美结论一律标 `[推断]`，不当作已验证事实

## 0. 质量标准定位（先校准期望）

Awwwards / Webby / FWA 是**面向表达型网站**的奖项（品牌官网、作品集、展会、编辑型体验）。Acaora 是长期使用的中文学习工作台，PRODUCT.md 明确写着「为第十二周做深度，而不是为第一分钟做惊喜」。因此正确的对齐方式是：

| 维度 | 奖项站的强项 | Acaora 应当继承的部分 | 不应照搬的部分 |
| --- | --- | --- | --- |
| 排版 | 字体尺度成为构图本身 | 一套可验证的字级、真实的中英混排处理 | 展示型超大字、实验字体动画 |
| 留白 | 用空白制造节奏与停顿 | 有意图的密度分配（安静页 vs 工作页） | 全站大留白（工作台需要密度） |
| 视觉层级 | 一屏一个明确主张 | 真正的一号层级与可扫描的次级信息 | 营销式单一 CTA |
| 色彩 | 强色相 + 严格配比 | 单一强调色 + AI 语义色的纪律 | 大面积品牌色铺陈 |
| 动效 | 有主张的转场与滚动编排 | 状态转场的因果感、可中断、有上限 | 滚动劫持、3D 视差、入场门槛 |
| 微交互 | 每个元素都有回应的质感 | 全状态覆盖（hover/active/focus/disabled） | 循环装饰动效 |
| 响应式 | 移动端是重新构图而非缩放 | 断点处的信息重排 | 首屏视频/WebGL 媒体墙 |
| 原创性 | 签名式的视觉记忆点 | 一个贯穿全站的识别点 | 为独特而独特 |

**本次审视的核心结论**：Acaora 的问题不是「不够炫」，而是**一套设计语言没有落到全部表面**。令牌层（`--brand`、白底、AI 青）是统一的，但每个路由各自长出了一套排版、色彩与形状，导致产品读起来像三个产品拼在一起。这正是奖项评审最容易扣分的「一致性」项，也是可以用工程手段解决的部分。

## 1. 做得住的（不要在这轮改动它们）

这些是本项目已经达到奖项站同等克制水准的地方，属既有资产：

1. **阅读区排版** `[实测]` /papers 正文用自托管 `Acaora Source Serif` 20px/1.65，阅读列宽约 76ch，字号选择器与专注模式齐备。这是全站工艺最高的一屏。
2. **总览的编辑式目录** `[实测]` /dashboard 用 46px serif 标题 + 32px 目录 + 细线分隔 + 右列次级记录，四入口等权、记录优先于元数据。方向正确，已获用户认可。
3. **克制的动效预算** `[代码]` 全局只有 19 条 `!important`，无 `transition: all`，无 `will-change`，无 `setInterval`。
4. **动效默认关闭** `[代码]` `light-curtain.tsx:42` `useState(true)` 即「Motion is opt-in」，配合右下角开关，是比多数奖项站更负责的默认值。
5. **无障碍底座** `[代码]` 全局 `:focus-visible` 兜底、`prefers-reduced-motion` 全局 kill switch、`prefers-reduced-transparency` 处理、移动端抽屉有焦点陷阱与 Escape 回焦。
6. **语义分层** `[实测]` AI 层与原文层在视觉上可区分，符合 PRODUCT.md 的第三条机制。

## 2. 修改清单

按「收益 ÷ 风险」排序。每条给出证据、位置与验收方式。**S 级建议立即做，M 级按页面推进，L 级作为一次独立的重构专项。**

### S 级：低风险、单点、可立刻验证

#### S0. 侧栏展开时遮挡页面标题与正文（本轮新发现，优先级最高）`[实测]`

- 现象：在任意工作台页面把指针移到侧栏（或键盘聚焦其中）后，侧栏从 72px 展开到 232px，但**内容列没有让位**。展开态直接把页面 H1、副标题与正文左缘压在自己下面。
- 实测证据：在 1440×900 的 /courses 上强制 `data-expanded="true"` 后截图，可见「课程中心」页标题被完全盖住，课程名被切成「概率论与数理统计」（首字被遮），段落首字与「登录后可保存学习记录」同样被盖。
- 机制 `[代码]`：`.app-sidebar` 为 `position: absolute; width: 72px; z-index: 20`，外层 `.sidebar-auto-slot` 为 `position: sticky; z-index: 40` 且自身宽度保持 72px；展开只改侧栏自身宽度（`hover-navigation.css:11` → `233px`），外层轨道与内容列都不参与布局。因此这是一次纯覆盖。
- 影响：这是用户在**每次使用导航时**都会看到的一屏，遮挡标题属于肉眼可见的成品缺陷，且直接损害「产品被认真设计过」的判断。它也是全页 100% 复现、跨页面一致的问题。
- 修法（三选一，按项目偏好定）：
  1. 展开时让内容列同步让位（把轨道宽度做成参与布局的 `grid-template-columns` 过渡，或给内容列一个同步的 `padding-left` 过渡）；
  2. 展开只作为**覆盖式预览**，但必须保证不遮标题——例如侧栏展开层加半透明背景 + 内容不变暗，或让标题区在展开时不上移；
  3. 收起态直接给出文字标签（不做 hover 展开），用更宽的常驻轨道换取零歧义。
- 验收：1440 下把指针移入侧栏并保持，页面 H1 必须完整可读；键盘 TAB 进入侧栏时同样成立；截图对比展开前/后标题未被覆盖。
- 注意：不要用 `overflow: hidden` 掩盖，也不要靠提高标题 `z-index` 让文字浮在侧栏之上——那会让两者叠字。

#### S1. 主按钮出现四套颜色，且深藏青比初判更分散 `[实测]`
- 现象：「新建项目」「开始学习」= `#305fce`；/projects 空态「注册或密码登录」= `#111827`；/settings 空态「前往登录」= `#171e2e`；课程练习提交 = `#253e5b`。
- 位置（已逐一核对行号）：`globals.css:1389`、`globals.css:1170`、`courses.module.css:26`、`courses.module.css:48`。
- **复核追加**：同一深藏青还出现在找回密码与验证结果流程——`globals.css:895`（`.auth-result-page` 文字）、`:897`（图标底）、`:900`（结果页返回链接）、`:905`（重置提交按钮）。这些不是空态而是真实用户路径，说明这是全站色彩体系问题，不是两个孤立空态。
- 影响：同一产品里「可以点的主动作」有四种视觉，破坏色彩配比，且深藏青在浅底上的品牌联想为零；深色底上的白色文字会让人误读为另一种状态语义。
- 修法：以上全部改为 `var(--brand)` / `var(--brand-hover)`。`globals.css:1259` 的 `.data-context-strip strong { color: #171e2e }` 属文字色而非按钮，可保留但建议同时评估是否收敛到 `var(--text)`。
- 验收：`rg '#111827|#171e2e|#253e5b' app/` 后逐条确认，只允许保留已说明理由的文字色命中。

#### S2. 「保存资料」看起来像禁用 `[实测]`
- 现象：该按钮是 `var(--brand)`，但因未登录态 `disabled` 叠加 `white-theme.css:72` 的 `opacity: .6`，视觉上是一枚浅蓝按钮。用户读到的不是「未登录」而是「按钮坏了」。
- 修法：未登录时整块表单区改用与 /projects 一致的登录引导空态，不要留一个灰按钮在页首。
- 验收：未登录访问 /settings，页首不出现任何形式的活动按钮。

#### S3. 中文字体被施加反字距 `[实测]`
- 现象：`/` 主标题 62px、`letter-spacing: -3.1px`；`总览` H1 46px、`letter-spacing: +1.84px`；`论文研究` H3 32px、`+1.12px`。
- 影响：拉丁字体的负字距是光学修正；汉字字形宽度固定，负字距让字挤在一起，正字距又让长标题松散。两者都被真实截图证实。
- 修法：中文标题统一 `letter-spacing: 0`（或最多 `-0.01em`），把节奏交给字号与行高。拉丁串（课程代码、英文论文标题）保留现有处理。
- 验收：对比修改前后截图，中文标题不再出现字间挤压或松散。

#### S4. KaTeX 在首页加载 `[实测]`
- 现象：打开 `/` 时 `document.fonts` 中 20 个 KaTeX 字体全部注册。
- 影响：非数学页面的无谓字体流量。
- 修法：把 `katex/dist/katex.min.css` 从 `app/layout.tsx` 移到实际渲染公式的组件内。
- 验收：首页 `document.fonts` 不再出现 `KaTeX_*`；/courses 某含公式课时仍正常渲染公式。

#### S5. 焦点环有三种规格 `[实测/代码]`
- 现象：全局 `globals.css:1535` 为 3px；`workspace-refresh.css:17` 为 2px；侧栏另有 2px 与旧色 `#70dfc5` 残留（`globals.css:1215`，已被 `:1805` 覆盖）；`courses.module.css:28` 又是 3px `#456e9b`。
- 修法：确立 2px `var(--brand)` + `offset 3px` 为唯一规格，删除其余覆盖。
- 验收：TAB 巡游全站，焦点环宽度与颜色一致。

#### S6. 动画开关不记忆 `[代码]`
- 现象：`light-curtain.tsx` 的暂停状态无任何持久化，刷新即回到默认（关闭）。同时 `white-theme.css:27` 画布 `opacity` 无过渡，首帧硬切 `[代码]`。
- 修法：把用户选择写入 `localStorage`；画布显隐加 200ms 淡入。
- 验收：打开动效、刷新，开关仍为打开；首帧不闪烁。

#### S7. 交互元素缺失状态 `[代码]`
- 现象：`.literature-search button`、`.paper-annotation-actions button`、`.paper-annotate-paragraph`、`.annotation-entry button` 完全没有 `:hover` 规则；`:active` 只在按钮族存在，导航项、列表行、标签页、日志行都没有；`.ui-tabs button`、`.course-row`、`.project-list button`、`.journal-*` 没有 `:disabled`。
- 位置：`paper-reading.css:51,56,59,70`；`globals.css:1868`；`focused-workspaces.module.css:11,40`。
- 修法：补齐四态。验收：逐元素 hover / 按下 / 键盘聚焦 / 禁用各看一次。

#### S8. 版心宽度不统一 `[实测/代码]`
- 现象：/dashboard 有效版心 1240px；/courses、/data、/projects 铺满 1640px 外壳。根因是 `white-theme.css:198` 把 `globals.css:2045` 的 `1240px` 正文列置为 `none`，而 /dashboard 靠自己的 `overview.module.css:14` 兜底。
- 修法：恢复一个共享版心（建议 1240px 用于编辑式页面，1440px 用于工作台式页面），删掉页面内的重复兜底。
- 验收：在 1440px 下测四个页面的内容左右边界，风格分组内应一致。

### M 级：需要页面级推进

#### M1. 字号倒挂，标题层级在语义上失效 `[代码]`
- /courses：H1 `clamp(30px,2.6vw,38px)`（`operational-craft.module.css:4`）在 1425px 视口算出 37.05px，而课程标题 H2 `clamp(27px,2.8vw,38px)`（`workspace-refresh.css:66`）算出 38px。**子标题大于页标题。**
- /papers：H1 22px，同屏 `literature-search` 的 H2 为 36px（`reading-craft.module.css:106`）；文献条 H3 24px 大于小节 H2 14px（`:110` vs `:66`）。
- /data：面板 H2 18px，而 `chart-toolbar` H3 也是 18px（`globals.css:220`）。
- 影响：这是同时伤及视觉层级、可访问性（H 序错乱）与「排版是否有主见」的一项，属最高优先级。
- 修法：建立单一 `h1 > h2 > h3` 递降，见第 3 节 Type Scale。

#### M2. 全站没有统一字级 `[代码]`
- 各页实际生效的 H1：/`62px 500`、/dashboard `46px 500`、/courses·/data·/projects `37.05px 600`、/papers `22px`、/auth `clamp(26px,3.5vw,42px)`。
- `globals.css:58-69` 有一套 `--fs-display…--fs-caption` 令牌，但路由普遍用字面 `clamp()` 绕过它；`focused-workspaces.module.css:6,15,16` 的整段课程布局规则在 TSX 中零引用，是死代码 `[代码]`。
- 修法：确立本文件的第 3 节字级，所有路由消费令牌。

#### M3. 两套衬线、七个页面无衬线 `[实测/代码]`
- `/dashboard` 用 `Acaora Overview Serif`（`overview.module.css:2`，仅此一处消费）；`/papers` 用 `Acaora Source Serif`（`reading-craft.module.css:3`）；其余全部落回 `Segoe UI/PingFang`，且 `workspace-refresh.css:18` 强制控件收敛到无衬线。
- 影响：产品没有一个连贯的「声音」。奖项站通常 1–2 款字体贯穿全站。
- 修法：选一套衬线承载所有**标题与阅读内容**，无衬线只承载**控件与数据**。这是全站视觉性格的最大单点收益。

#### M4. 首页内容体量不足以支撑「网站」的评审 `[实测]`
- 现状：首屏（左文案 + 右产品截图 + 底部「工作区」三项列表）+ 页脚。工作区三项独占约 300px 高度但每项只有一行字。
- 影响：Webby 的「网站」类目看的是编辑与信息架构的完成度；当前首页更像一张封面。
- 方向（不虚构能力，只用 PRODUCT.md 已确认的事实）：把三条机制（本机文件优先、AI 是独立标注层、一个账户一份记录）写成可读的段落；把「七门课程 / 64 核心课 / 每节一个例题三道练习」这类**已确认的真实内容**作为可信度支撑；把隐私与 AI 的边界做成一段直白说明而非一个导航项。
- 禁止：编造用户评价、客户 logo、媒体引用、使用数据（PRODUCT.md 已明确列为不可虚构）。

#### M5. 侧栏在 1024 级窄桌面压到内容 `[实测/代码]`
- 现象：761px 以下切抽屉，761–1100px 之间保持 188px 轨道 + 展开态 232px。1024×800 实测未横向溢出，但 188px 约占 18% 宽度 `[实测]`。
- 修法：在窄桌面区间让轨道默认收起、hover 展开（已有机制），或把版心下限降到 1104px 以下。
- 验收：1024 / 1280 / 1440 三档各看一次首屏。

### L 级：一次独立的重构专项（建议配独立分支与回滚点）

#### L1. 间距与圆角失去尺度 `[代码]`
- 间距：4/8/12/16/24/32/48/64 尺度内约 830 次使用，而 10 个离尺度值合计约 843 次 —— **离尺度用量已超过尺度内**。最高频离尺度值：20px(131)、18px(131)、10px(120)、14px(111)、28px(77)、22px(61)。
- 圆角：全仓 44 种字面值，最高频 `9px`(36 次) 不在任何尺度内；容器另用到 15/16/19/20/22/24px。
- 修法：锁定 6 档圆角（6/8/10/12/14/18）与 8 档间距，用 `rg` 批量替换 + 截图比对。**必须逐段替换并比对，不要整文件正则横扫**（见第 5 节风险）。

#### L2. 旧层投影与新层「零投影」互相矛盾 `[代码]`
- `globals.css` 仍留约 78 条 `box-shadow`，其中 55–60 条在页面结构容器上；而 `workspace-refresh.css` 有 13 条显式 `box-shadow: none` 试图取消它们。
- 影响：同一产品里「页面结构是否承载高度」没有结论，视觉重量随机。
- 修法：决定一条规则（建议：**页面结构不投影，仅浮层/菜单/焦点环可投影**），在旧层系统性清零。

#### L3. CSS 分层靠「后写者胜」 `[代码]`
- 6 张顶层样式表，`globals.css` 4270 行内含两代世界（同一选择器重复定义，如 `.auth-shell` 三处、`.plab-workbench` 十一处）；跨文件靠 `white-theme.css` → `workspace-refresh.css` 顺序覆盖；路由 module 再用 `.craft.craft :global(...)` 双写类名提特异性。
- 影响：任何改动都要先算特异性，改一处掉三处——这是 M1/M2/S8 反复出现的机制。
- 修法：把「当前有效值」提为唯一 token 块，旧世界的 selector 逐段删除（先备份、后按块删，不要按行删）。

#### L4. 动效时长与缓动没有尺度 `[代码]`
- 时长：18 种（0/15/80/120/140/150/160/180/200/220/240/260/280/360/380/420/600/650ms）。已声明令牌 `--dur-1..3`（120/160/200）中 `--dur-1` 与 `--dur-3` **使用次数为 0**。
- 缓动：`var(--ease-out)` 62 次、关键字 `ease` 32 次、另有 4 种自定义贝塞尔。
- 修法：收敛为 120 / 180 / 240 / 320ms 四档 + 两条曲线（进入用 `cubic-bezier(.16,1,.3,1)`，退出用 `ease-out`）。

#### L5. 布局属性参与动画 `[代码]`
- `hover-navigation.css:9` 侧栏 `width 72px→232px`，每帧触发布局；`workspace-motion.css:51,53` 直方图 `height 420ms`、散点图 `left/bottom 420ms`；`course-shell.tsx:17-21` 用 `flushSync` + 前后 `getBoundingClientRect` 强制同步布局；`use-paper-motion.ts:21-24` 每次提交测量四个表面。
- 影响：在中低端笔记本（本产品的目标设备）上，这是「点击等待」体感的来源之一 `[推断]`。
- 修法：侧栏改 `transform: translateX` + 内容 `margin-left` 一次的写法，或接受 `grid-template-columns` 过渡；图表改 `transform: scaleY/translate`。

## 3. 建议的 Type Scale（可直接作为令牌草案）

```
display-lg  62px / 1.15 / 500   serif   仅首页主主张
display     46px / 1.15 / 500   serif   页面主标题（/dashboard 现用值）
title-1     32px / 1.30 / 500   serif   内容标题（课程名、论文名）
title-2     24px / 1.35 / 600   sans    区块标题
title-3     18px / 1.45 / 600   sans    卡片/面板标题
body-lg     20px / 1.65 / 400   serif   论文正文（/papers 现用值）
body        15px / 1.60 / 400   sans    界面正文
label       13px / 1.40 / 500   sans    元数据
caption     12px / 1.40 / 400   sans    次要说明
numeral     28px / 1.10 / 600   sans    tabular-nums 指标数字
```

要点：

- **h1 永不小于同屏 h2**。若课程名需要比页标题更大，正确做法是**去掉页标题**，让课程名成为该页唯一的 H1，而不是制造两个竞争的一号。
- 中文标题 `letter-spacing: 0`；拉丁串可保留 `-0.02em`。
- 数字统一 `font-variant-numeric: tabular-nums`。
- 行高：中文正文 1.7–1.8，标题 1.15–1.35。

## 4. 八维自检与优化方案

### 4.1 排版 Typography

- `[实测]` 字号倒挂（M1）、三套页面标题尺度（M2）、两套衬线（M3）、中文字距（S3）、KaTeX 全局加载（S4）。
- **优化方案**：落地第 3 节字级为单一令牌源；选定一款衬线贯穿标题与阅读；中文去掉反字距；数字启用 tabular-nums；`text-wrap: balance/pretty` 已存在（`white-theme.css:23-24`），保留并扩展到卡片标题。
- **验收**：在 1440px 下逐页量 H1/H2/H3 的计算字号，确认严格递降；截图对比中文标题的疏密。

### 4.2 留白 Whitespace

- `[实测]` /dashboard 与 /settings 的下半屏大面积空置，而 /courses 的 12 节清单在窄容器里排成两列后行高偏紧；/data 卡片内边距与卡片间距不构成同一节奏。
- `[代码]` 离尺度间距（20/18/14/28/22px）超过尺度内用量 —— 空白是被随手决定的，不是被设计的。
- **优化方案**：把留白定义为「区块间距」而非「元素内边距」的决策：区块间 `48/64`，区块内 `16/24`，元素间 `8/12`。空置区域不要用假内容填，改用一条真实的、可用的承接（例如 /dashboard 右列在无记录时给出「导入第一篇论文」的直接入口，而不是一段说明）。
- **验收**：把每页截图缩到 25% 并排观察，空白应呈块状节奏而非随机。

### 4.3 视觉层级 Hierarchy

- `[实测]` H2 > H1 的倒挂；/papers 同屏出现 22/30/36/44px 四种「像标题」的字号；/data 的「样本概况」三个指标藏在首屏之下。
- **优化方案**：一屏一个支配元素。工作台式页面（/data、/courses）把关键真实数字提到首屏；阅读式页面（/papers、/dashboard）保持单一主张。删掉竞争层级的第二标题。
- **验收**：每页截图模糊化（高斯 8px）后仍能看出唯一的一组主次关系。

### 4.4 色彩 Color

- `[实测]` 四种主按钮色（S1）；禁用态把主按钮涂成浅蓝（S2）。
- `[代码]` AI 青 `--ai-vivid #14b8a6` 与 `#66ebcf` 旧值并存；`globals.css` 内仍留 `#171d2b`、`#101526`、`#253e5b` 等旧基座色。
- **优化方案**：确立「一个强调色 + 一个语义色」的纪律：`--brand` 只用于可点击的主动作；AI 青只用于 AI 产出；其余全部中性。深藏青只作为深底容器背景（若使用），不作为按钮色。
- **验收**：全站截图取色统计，主按钮背景色唯一。

### 4.5 动效 Motion

- `[代码]` 18 种时长、`--dur-1/--dur-3` 零使用、侧栏动画 `width`、图表动画 `height/left/bottom`、两套自定义贝塞尔。
- **优化方案**：四档时长 + 两条曲线；只动 `transform`/`opacity`/`color`/`box-shadow`；侧栏改位移；图表改 `transform`；给「工作台切换」这一处保留一个可辨识的品牌级转场（当前 `workspace-course-open 360ms` 已有雏形，把它收敛成唯一的长动效）。
- **验收**：DevTools Performance 录制侧栏展开与图表切换，确认无 Layout 阶段的逐帧开销。
- **注意**：本产品**不要**引入滚动编排或 3D 视差——目标设备是笔记本，且 PRODUCT.md 明确长会话优先。

### 4.6 微交互 Micro-interaction

- `[代码]` 七个交互原语缺 `:hover`、`:active` 只覆盖按钮族、若干原语无 `:disabled`、焦点环三种规格。
- **优化方案**：建立状态矩阵（hover / active / focus-visible / disabled / selected），逐原语补全；按下反馈统一 `scale(.985)` 或 1px 位移，时长 80ms；不引入循环动画。
- **验收**：对每个原语做一次四态截图。

### 4.7 响应式 Responsive

- `[实测]` 390px 与 1024px 均无横向滚动；手机端 /dashboard 单列、/courses 折叠目录、/papers 独立标签，结构成立。
- 缺口：761–1100px 区间侧栏占宽偏大 `[实测]`；`globals.css:279,383` 仍留 `clamp(32px,4.7vw,58px)` / `clamp(34px,5vw,62px)` 的旧 PaperLab 标题 `[代码]`；`app/papers/original-pdf.module.css` 无 reduced-motion 块 `[代码]`；首页主视觉素材 639×399，在 1440 屏与高 DPI 下偏软 `[实测]`。
- **优化方案**：补 1100px 中间档；清理旧路由标题规则；补 `original-pdf` 的 reduced-motion；首页样机改为真实 DOM 截屏或 2x 素材。
- **验收**：390 / 768 / 1024 / 1280 / 1440 / 1920 各截一次；对比 200% 缩放下的素材清晰度。

### 4.8 原创性 Originality

- `[实测/推断]` 已有原创资产：随光场与「动效开关」、hover 展开的导航轨与 FLIP 选中标记、编辑式总览、论文阅读区。
- 缺口 `[推断]`：总览的编辑式语言只用在一页；首页仍是「左文案 + 右截图」的通用构图；装饰性光带在每屏重复出现，削弱了它的记号作用。
- **优化方案**：
  1. 把总览确立的编辑式语言（细线分隔、字级主导、无卡片）推广为**工作台式页面的公共语法**，而不是只属于一页的风格。
  2. 给产品一个唯一签名：建议是**「纸质层」**——论文纸面、课程页面的薄边与细线使用同一套 `paper-layer 3px` 语言，让「这是学习材料」成为视觉记忆点。
  3. 首页减少装饰重复：光带在一屏出现一次即够，把第二屏的注意力让给内容。
  4. 不作弊：不造假数据、不加无因果的动画、不为独特牺牲可读性。

## 5. 执行风险与回滚

| 风险 | 触发点 | 规避 |
| --- | --- | --- |
| 按行删除 CSS 留下孤立选择器碎片 | L1/L2/L3 的批量替换 | **按规则块删，不按行删**；每次替换前后各存一份截图与 `git diff --stat` |
| 整文件正则替换字号导致隐藏倒挂 | M1/M2 | 先输出「选择器 → 当前有效字号」清单，改完用同一脚本复测 |
| 改共享令牌影响未在清单内的表面 | L1/L3 | 一次只改一个令牌族（先字号、再间距、再圆角），每族一次构建 + 一次截图批 |
| 视觉回归基线被自动更新掩盖 | 全轮 | 不自动更新 Playwright 基线；用未改动的基线做对照 |
| 窄桌面区间判断错误 | M5 | 以 1024/1280 实测为准，不靠 media query 推断 |
| 首页新增内容超出已确认事实 | M4 | 只用 PRODUCT.md 已确认的事实；不编造评价、数据、logo |

**建议的提交节奏**：S 级一批（`fix: converge primary button color...`）→ M1/M2/M3 一批（`refactor: unify type scale`）→ S8/M5 一批 → L1/L2/L4 一批 → L3 单独分支。每批都满足：构建通过 + 相关测试通过 + 一组前后截图。
