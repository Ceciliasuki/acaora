# 研究工具贯通与项目协作

用户要求将此前建议全部实施，并明确“完成后部署”。本轮在八项专业研究能力上补齐以下真实操作，课程仍保持相对独立；没有重做 Dashboard 或阅读器。

| 能力 | 入口与实际行为 |
| --- | --- |
| 依赖与失效传播 | 项目 → 关联与写作。运行保存实际数据、字典、规格与方案版本；可补充人工关联。SHA-256 内容变化、来源归档或循环关系会沿依赖传递待核验状态，行政备注不单独使数据失效。历史运行只能使用实际留存的历史来源，不推定不存在的基线。 |
| 多表合并与样本审计 | DataLab 当前表 → 多表合并。支持最多五个联合键、left/inner/full，以及一对一、多对一、一对多。拒绝意外基数和多对多；缺失键不互相匹配。预览未匹配、重复、缺失、输出行数后明确应用，保留左表先前处理步骤和变量字典。合并凭证只有指纹与计数，原表行不上传。 |
| 绑定结果的正文 | 项目 → 关联与写作 → 正文结果块。从成功运行挑选完整精度指标、显示名称、单位和精度，保存固定正文与来源版本；可引用已确认文献和本机匹配的图表。小 p 值显示为阈值形式，避免舍入成零。更新来源不改写旧文字，导出需明确确认待核验稿；服务器拒绝伪造运行数值和未确认文献。 |
| 识别设计与因果图 | 项目 → 方法与检验。可编辑变量、方向边、处理/结果和调整集，诊断图内后门路径、碰撞点及其后代、处理后调整；拒绝环与超限探索。图由研究者声明，路径阻断不等于真实因果识别成立。 |
| 功效与完整假设族 | 同一入口。两独立组、等样本量、双侧正态近似的功效、样本量与 MDE，说明有限样本和复杂设计限制；全部计划假设保留，结果齐备后才做 Holm/BH/Bonferroni 校正，保存原始和校正 p。运行引用需与原始指标一致。 |
| 本地 Python/R 执行 | DataLab 当前结果或快照 → 本机执行。下载复现 ZIP，解压到独立目录，运行固定的 local-runner.py；连接 127.0.0.1 服务、输入仅本页保留的随机会话令牌、核对环境锁后发送处理表。固定脚本、固定运行时、单任务、超时、输入/输出预算；相同任务重试返回同一凭证。脚本或依赖变化要求重启并重新确认。无任意代码执行入口、无自动安装。 |
| 显式项目协作 | 项目 → 项目协作。默认私有，由所有者生成七天单次邀请、选择查看或编辑权限并自行交付。链接 token 放在片段中，数据库仅存哈希；接收者先预览范围再确认加入。所有者可调整或撤销权限，相关未使用邀请同时失效。记录保留所有者与实际作者；只读成员不能写，编辑成员不能转移所有权、删项目或管理成员。 |

## 数据与边界

项目只同步研究元数据、摘录、配置、指纹与汇总。原始数据、原始 PDF、完整本机快照及本地运行返回文件仍需自行保管。成员共享范围只限这个项目；原文导航不授予个人论文库或原文件访问。撤销不能收回成员此前自行导出的副本。

外部完整指标核验覆盖描述统计、相关回归、OLS 和配对 t。其他方法可本地执行及在浏览器重算，但部分外部指标不会被判为完整复现通过。原生 R 的 JSON/哈希入口依赖 jsonlite/digest；本机缺少这些包，未声称完整原生 R 端到端验收。Python 科学运行已有真实子进程证据，CI 新增固定依赖的 HTTP 实际执行门槛。

合并上限为 100,000 行、2,000 列、5,000,000 输出单元，预分配前检查。因果图上限 30 个节点、120 条边、10,000 条探索路径。历史预算、备份和导出上限沿用八项能力记录；达到限制报错，不静默丢弃。

## 数据库与兼容

迁移 `20261025041118_research_connections_and_collaboration.sql` 已应用到核实项目 `pxbcigfzcsfkttzmiork`，线上登记版本 `20261025065901`。只扩展记录种类、作者列与成员/邀请结构，保留现有项目和记录；不自动创建邀请或成员，不迁移旧正文、原始数据及课程。

公开 RPC 为 invoker，受限 private helper 为固定 search_path 的 definer。成员和邀请无客户端直接写权限；邀请表启用 RLS 且没有读策略是有意的默认拒绝，仅由私有函数访问。安全顾问新增的信息级“RLS enabled no policy”与此相符，非对外公开；原有泄露密码防护警告仍存在，未改变账户配置。

项目资料使用服务端单调时间戳和乐观锁。依赖、正文及假设族写入会锁定同一项目并检查记录序号和项目版本，防止校验后来源改变。重复响应采用固定操作身份；账户切换与迟到返回有隔离。协作备份恢复成当前账户的新私有项目，保留原作者来源，不复制成员和邀请。

回退前端时保留新增表与历史，禁止为回退删表。原有项目元数据兼容；回退版本不能编辑新记录种类，先保留备份并恢复支持的客户端。

## 证据

新算法单元覆盖合并基数/缺失/预算、DAG 路径与碰撞点、功效与 p 校正、来源投影/传播/循环、配对 t 独立 SciPy 对照。PGlite 验证所有者/编辑/查看/无权限四类身份、邀请、作者、撤销、旧邀请拒绝、并发和重试。API 拒绝篡改数值、未知引用、角色数组和账户变化。

浏览器场景覆盖合并 5、方法规划 5、本地执行 2、关联与协作 4 个不同场景。关联正文在 1440px/375px 无页面横向溢出，作用域 Axe 检查通过；实际 DOCX 含保留旧数值和待核验状态。发现并修复空账户邀请被新建项目弹窗阻挡的问题。受控验证使用合成项目与 mock 账户，没有向真实成员发送消息或写真实研究内容。

生产构建已编译、类型检查并生成 26 个页面；隔离目录的预取步骤显式使用同一构建目录后生成 10 路由/30 文件。第一次后处理默认读到开发目录的失败不作为通过证据。构建生成的类型路径改动已撤回。源码 lint 排除了本机隔离构建与诊断目录；正式 CI 在干净检出中执行既有完整门槛。

最终 CI、合并与线上完整 SHA 以本次[发布记录](../releases/2026-10-25-research-workbench.md)及正式 `/api/version` 为准。数据库应用不代表前端已上线。
