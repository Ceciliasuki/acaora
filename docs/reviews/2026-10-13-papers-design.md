## 八项自检

| 维度 | 已实施与检查 | 判断及下一步优化方案 |
| --- | --- | --- |
| 排版 | 论文标题桌面 28px、手机 23px；正文桌面 19px、手机 18px，行高 1.85；工具标签使用原有无衬线字体。标题改为自适应换行编辑框，四种宽度均检查完整显示、编辑和 Enter 结束编辑。 | 标题、正文、操作已有明确字体角色。下一步可试用有明确授权的自托管中英文字体，比较真实中文论文与英文论文的阅读效果；当前使用系统衬线字体，跨平台形态仍会不同。 |
| 留白 | 正文最大行宽 72ch，保持居中；正文、译文、章节使用不同间距。通过对称滚动条预留修复 5px 中心偏移，原有居中断言通过。 | 留白支持阅读而非装饰。极长标题在平板上仍占较多垂直空间，可在真实使用反馈后评估阅读时的紧凑标题状态，保留完整标题与编辑入口。 |
| 视觉层级 | 仅导入保持实心主按钮；工作模式及章节用细线指示当前位置，论文库、笔记使用图标和展开状态。笔记和库保持按需出现。 | 正文优先级清晰。若真实论文目录很长，可进一步评估更紧凑的目录布局与当前章节定位，先验证真实长论文需求。 |
| 色彩 | 保留品牌钴蓝，正文使用 #252b36，次级信息 #5e6877，正文白色、工具边栏 #f6f8fb；背景透明度减为原层的 28%。批注颜色和 AI 语义保留。 | 新增正文与标签组合达到 AA 所需对比度，阅读与检索区域的 axe 严重/致命问题为 0。后续应以不同屏幕、亮度和字体渲染验证长时间阅读舒适度，自动检查不能替代这一点。 |
| 动效 | 保留已有模式指示条、面板切换和批注反馈；正文不逐段入场。新增按钮颜色过渡 160ms；减弱动效设置取消新增过渡，原有 reduced-motion 合约保留。 | 动效解释状态。仍保留全站背景动效开关与原有渲染机制，本轮仅降低阅读页视觉强度；低功耗设备是否需要阅读时暂停背景，应依据真实设备测量决定。 |
| 微交互 | 标题悬停、聚焦与编辑光标可见；按钮使用同族图标，展开状态继续由 aria-expanded / aria-pressed 表达；章节新增 aria-current；选择颜色、批注、焦点返回和保存反馈保留。 | 反馈有任务意义。下一步优先在真实手机上验证文字长按选择、跨段批注和软键盘下的工具位置，而非再增加悬停特效。 |
| 响应式 | 375 / 768 / 1024 / 1440px 长标题检查通过，无页面横向溢出；手机独立面板标签保留；修复吸顶标签与主菜单重叠。原 PDF、移动滚动定位与笔记切换回归通过。 | 四类浏览器视口已有证据；没有声称实机 Safari、Android 或全部缩放比例均已验收。后续优先真机与 200% 缩放检查。 |
| 原创性 | 使用论文书页、页边笔记、索引与引用结果的产品语义组织界面，避免展示型大标题、虚构指标或装饰卡片。原界面身份与功能保留。 | 这是对现有产品的明确排版优化，不能据此证明达到奖项网站的原创性门槛。下一阶段可为长论文目录、引用回跳和个人批注建立更有辨识度的连续交互，但应先做可审阅方案和真实用户验证。 |
