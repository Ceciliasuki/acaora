# 分类回归、事后比较与论文图表

2026-10-21，本地交付；未部署到 acaora.cn。本轮按用户指定的 1→2→3 顺序实现，不改动线上数据和现有同步合同。

## 分类解释变量与参考组

“多元回归”和进阶 Logistic、聚类 OLS、个体固定效应、交叉验证均可显式选择分类解释变量与参考组。数值编码的类别也可选择为分类字段，需先取消同一列的数值角色。不自动把类别文字转换成有序数字。

- 每字段 2–12 个有效类别，最多 6 个分类字段；编码后与数值解释列合计最多 12 列。可仅使用分类解释变量。
- 使用省略参考组的哑变量编码。显示标签如 `kind [干预 & A vs 对照组]`，编码表/模型配置/方案保留原字段、水平和参考组。OLS 系数为条件均值差；Logistic 系数为 log odds 差，OR 的既有解释保持。
- 所需字段整行排除，类别按去除首尾空格后的精确文本区分；现有 NA/空值规则仍适用。无参考水平、过高基数、不支持的标签、角色冲突、编码后超限和秩亏明确报错。固定效应仍不能识别主体内不变的类别。
- 原数据不变。内部列标识不会覆盖原表头，显示上下文不通过含糊的子串替换来改变用户变量名。
- 随机/主体/时间验证均在**各折训练集**拟合类别水平和缩放。训练参考组缺失、只有一个训练水平、验证集出现未见类别时明确失败，不能将新类别当参考组或用全样本类别表偷渡信息。逐折输出实际编码。

OLS 方案现在导出 `acaora-ols-v2`；进阶方案导出 `acaora-advanced-v3`。分类字段与参考水平可载入、重新映射并核对。保留不含新功能的 OLS v1 / 进阶 v2 数值方案读取兼容；禁止旧引擎文件夹带新类别/事后比较设置。分析记录仍是审阅记录，方案应用不自动拟合。

本轮未实现交互项、自动合并稀有类别、缺失插补、Firth 或正则化。这些不会在未说明的情况下被用来消除拟合错误。

## 成对 Welch 检验与 Holm 校正

进阶方法新增“成对 Welch 检验（Holm 校正）”，当前合计十二种进阶方法。

- 先选“所有组间比较”或“各组对参考组”。最多 12 组，分别最多 66 或 11 个比较；每组至少两个有效观测、正且有限样本方差。
- 按所选范围构成**一个比较族**，每对双侧 Welch 检验使用其 Satterthwaite 自由度，Holm step-down 保持原比较顺序输出调整 p。
- 表格包含 A/B 组、N、A−B 均差、标准误、t、自由度、原始 p、Holm p、逐对 95% 区间和校正后的 α=.05 拒绝标记。比较族大小、参考组和计算口径进入配置、上下文、CSV 与方案。
- 明确逐对区间未经多重调整，不能称作同时置信区间；Holm 只覆盖当前指定比较族。非拒绝不证明等价，均差不自动成为因果效应。不按 omnibus p 自动挑选某组比较，也不悄悄排除无法检验的组。

`criticalT95` 扩展为支持正的非整数自由度，以正确覆盖 Welch 区间；原 OLS 整数自由度数值不变。

## 论文图表与实际导出

拟合结果内增加“论文图表”：

| 结果 | 图形 | 保留的内容 |
|---|---|---|
| OLS / Logistic / 聚类 / 固定效应 | 系数与 95% 区间图 | 不绘制截距；原始变量/类别差异标签，零参考线，实际系数与区间。Logistic 横轴明确 log odds |
| PCA | 碎石图 | 所有特征值，PC 序号，标准化口径 |
| 交叉验证 | 各折 RMSE / MAE | 同一因变量单位，线型与点形双重区分；N 为有折外预测的评估数 |

标题、坐标轴/单位和图注可修改，提供 900/1200/1600px 图宽。SVG 是独立矢量文件，文字/线/点可在矢量编辑器继续编辑；PNG 经实际浏览器 SVG→Canvas 栅格化，以所选宽高的 2 倍导出，不把矢量文件改扩展名当作 PNG。

来源、N 和方法显示在图中，SVG metadata 还保存完整精度的绘图数值、设置、实际模型配置和计算上下文。编辑图名不改变数值或模型；改草稿设置但未重新拟合时，图仍对应明确标旧的实际结果。CSV 继续是完整数值表。

所有标签和 JSON metadata 经过 XML 转义，不插入外部资源、脚本或 foreignObject。尺寸预算最多 4096px 高、2× 导出最多约 3200 万像素；标签过长明确要求缩短源列名/图注。字体使用设备已有字体，SVG 未嵌入字体，跨设备可能替换。手机预览可键盘/触摸横向滚动，导出尺寸不缩水。
