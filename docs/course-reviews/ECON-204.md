# 微观经济学内容审查

2026-10-03，代理内容、模型与计算核验；参考上海交通大学 2021《中级微观经济学》公开大纲的经典范围，不声称最新院校教学计划、官方认证、学分等效或教学效果验证。尚未经过任课教师审阅。

## 内容与目标

11 章、12 节完整讲义、24 个完整例题、72 道随堂题；11 章各另有 8 题，共 88 题；期中/期末各 12 题，总计 184 道原创题。题目覆盖概念条件、数值、推导和迁移。开放题仅有参考答案与要点，不伪造自动得分。

核心范围包括最优化/KKT/角点与均衡、偏好/消费/替代互补、需求弹性/显示偏好、消费者对偶/Slutsky/CV与EV、跨期借贷/期望效用/保险、生产/成本/短长期、竞争/垄断/税归宿、Nash与寡头/承诺、要素市场/买方势力、纯交换/福利定理、外部性/公共品、逆向选择/信号/合同及综合政策报告。第八章拆两节，给博弈与要素分别保留推导、反例和练习；全部旧 ID 保留。

正文从原问题和可行域推导，不把全部模型压成一个内点切线；原有局部非饱和、可微、凸/凹、市场完整、竞争、信息与可执行性等条件在对应结论处标记。存在定理、混合策略存在和 Afriat 等仅介绍结果/条件而未完整证明的部分如实说明。显示偏好中区分反向严格关系与无差异，不将两个等预算观测随意判作严格循环。

信号例题只检查明确路径的激励约束，提醒完整均衡还须所有偏离、离轨信念和报价；合同弱 IC 明确无差异与平局。不能把“满足参与”当成“激励成立”，也不把最低工资在特定买方模型中的雇用提高当成现实因果。

逐章对标与正文依据见 `content/courses/ECON-204/coverage.json`。公开大纲只用于范围对照，正文、教学参数、图形与题目独立编写。

## 独立计算与图形

独立入口 `.course-checks/Scripts/python.exe scripts/verify-course-calculations.py --course ECON-204`。实际参考模块 `scripts/course_calculations/econ204.py`，使用固定版本 NumPy/SciPy，未依赖作者答案生成参考值。

90 项检查通过，覆盖全部 74 个数值例题/数值题，并额外检查模型边界、可负担性、合同约束及图形。方法包括原目标/约束的数值优化、互补/替代/合同的线性规划、均衡和边际效用的根求解、成本/福利的数值积分、数值偏导、Joint FOC 系统与分段全局比较。输入、方法、答案、容差、实际误差记录于 `calculations.json`。跨期对数效用在最优点目标值较平，改用单调边际效用根求解保留原 1e−6 答案门槛，未改变正确答案或放宽评分。

两幅原创 SVG 分别展示预算与等效用相切、税前/税后均衡和无谓损失。参考程序解析实际 SVG 的每条 101 点曲线，逆变换屏幕坐标后核对模型函数；也解析实际损失多边形并用鞋带公式检查面积。预算切点斜率、价格与交易点均与例题一致。来源仅限同课程静态文件，图有文字条件、替代说明、键盘滚动和原尺寸入口，不靠图形取代全部推导。

已核对的边界包括：零收入、角点、互补不可微、替代需求多值、不可分单位、负数量/无交易、过高税额、沉没与可避免成本、短期停产/长期退出、借贷限制、非公平保险、正常/劣等/Giffen、收入效应下剩余差异、零概率差无法激励、绑定 PC/IC、多均衡和福利/分配区别。所有无实际来源标签的数值为教学构造，不是市场测量或政策研究发现。
